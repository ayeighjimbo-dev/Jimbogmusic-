# jimbogmusic.com

The official Jimbo G website — "Music for Broken People."

A single self-contained `index.html` (recovered from the July 2026 update package in Google Drive) with Spotify and YouTube embeds, the Fan Lab, and the Vault. No build step, no local assets — fonts and images load from Google Fonts and Postimg.

Hosted free on GitHub Pages: https://ayeighjimbo-dev.github.io/jimbogmusic/

To point jimbogmusic.com at this site once the domain renewal is sorted, add a `CNAME` file containing `jimbogmusic.com` and point the domain's DNS at GitHub Pages.
